## ✨ A little about me

Hi! I'm a **full stack developer with a backend heart**. I love building the parts of a product that people never see and always feel: the APIs, the data models, the queues and the auth that keeps everything safe. Then I take it all the way to the screen with React and Next.js, so a feature goes from an idea to something real people can click.

I'm a **competitive programmer** too, so I get happy about clean algorithms, tricky edge cases and a solution that runs in the time limit. 🧩
